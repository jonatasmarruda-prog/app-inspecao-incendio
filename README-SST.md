# Sistema Profissional de Inspeção SST

Aplicação web responsiva para inspeções de Segurança do Trabalho e Combate a Incêndio, preparada para uso em celular e computador.

## Escopo
- Combate a Incêndio
- Extintores
- Hidrantes
- Iluminação de Emergência
- Sirenes/Alarmes
- Investigação de Acidentes
- Histórico, edição, exclusão e relatórios
- Fotos comprimidas sem corte
- Assinaturas em Canvas
- PDF construído diretamente dos dados
- Autosave/local e sincronização Firebase quando configurada

## Firebase
Projeto-alvo: `app-inspecao-sst-79aa6`.

A configuração Web do Firebase deve ser fornecida no ambiente do projeto; não colocar credenciais administrativas no cliente.

## Execução
A aplicação é estática e pode ser servida pelo GitHub Pages, Firebase Hosting, Netlify ou outro servidor HTTPS. Câmera, GPS e compartilhamento funcionam melhor em HTTPS e em navegadores móveis compatíveis.

## Critérios de aceite
Consultar `Texto colado.txt` da especificação original. O fluxo deve ser validado em Android, iPhone e computador antes de considerar a implantação de produção concluída.
